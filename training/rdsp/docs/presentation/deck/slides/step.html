One training step

Each stage runs its own schedule; the driver only starts and finishes the step

1 · Hand out the work

The driver takes exactly N microbatches and sends each stage one command: its forwards and backwards in 1F1B order.

2 · Stages work on their own

Each GPU receives an activation, runs forward, sends it on; later receives a gradient, runs backward, sends it back.

3 · Nobody steps alone

Only when every stage reports all backwards done does the driver tell all of them to run the optimizer, exactly once.

4 · Failures are clean

Before the optimizer: a clean error, links rebuilt, retry is exact. During it: the pipeline locks until restored from a checkpoint.

Ray calls per step at 8 stages: about 944 in the first design, about 16 now.

1F1B = one-forward-one-backward: each stage does a few warm-up forwards, then alternates, which bounds how many activations it keeps in memory. The first design had the driver send every forward and backward as a separate Ray call; the redesign sends one call per stage per step plus the optimizer apply.
