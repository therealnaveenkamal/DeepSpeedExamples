What changed

One command per stage per step. Two extra NCCL groups per GPU, one per direction, carry activations and gradients. Numbers are bit-identical to the first design.

One group per direction avoids a stage's gradient receive queueing behind its own activation send on an NCCL stream. After a failed step the links are aborted and rebuilt immediately so a stuck GPU transfer can't later kill a worker. The old path remains available as RDSP_DISPATCH=driver. 8-stage throughput is 2.1x the first design; both designs measured on H200 machines (separate machines, allow ~20%).
