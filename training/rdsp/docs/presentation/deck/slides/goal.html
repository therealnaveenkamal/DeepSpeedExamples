The goal

Split a model by depth, and let each piece have its own GPUs

Split by depth

Each stage owns a run of consecutive layers. Only activations cross between stages: once per boundary, per microbatch.

Stages are not equal

The stage holding the output head does about twice the work of a middle stage (85% vs 29% busy in our early runs). It should be allowed more GPUs.

No forks

DeepSpeed and Ray are used only through their public APIs: zero lines changed in either, checked against the pinned DeepSpeed source.

engine, _, _, _ = rdsp.initialize(model=hf_model, config=ds_config,
    pipeline_config=rdsp.PipelineConfig(stages=4), loss_fn=loss)
loss = engine.train_batch()   # one call = one optimizer step

The user-facing API mirrors deepspeed.initialize. The optimizer and scheduler come from the ordinary DeepSpeed config and are built inside each stage, so initialize returns None for them rather than a look-alike object.
