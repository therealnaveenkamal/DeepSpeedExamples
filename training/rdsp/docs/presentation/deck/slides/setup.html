Benchmark setup

Same weights, data, kernels and chip; compared only on the same machine

How it was run

  • Megatron-Core's own 1F1B schedule in a lean training loop, fusions on
  • rdsp, stage-local design, Liger fused kernels
  • 150 steps of 16 microbatches × 2,048 tokens, at 1, 4 and 8 GPUs
  • Pinned H100 (checked on every GPU); all setups back to back on one machine per GPU count
  • One image: torch 2.9, CUDA 13, DeepSpeed (pinned), Megatron-Core 0.19.2

Gradient summingrdsp bf16; Megatron fp32 (default) or bf16
Megatron's HF weights were mapped by hand into its fused layout; every Megatron parameter is checked to receive exactly one weight, and the layer coverage across ranks is checked. The one remaining mismatch is gradient summing precision: DeepSpeed ZeRO-0 bf16 sums microbatch gradients in bf16; Megatron defaults to fp32 (its --grad-reduce-in-bf16 option matches rdsp). Megatron also keeps fused weight-gradient accumulation and disabled Python GC, which only help it.
