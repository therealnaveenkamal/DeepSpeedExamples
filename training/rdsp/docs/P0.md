## Initial support row (default-deny; the only row targeted through P6)

Encoded in `src/ray_deepspeed_pipeline/support_matrix.py` as `FIRST_ROW`:

- dtype BF16; 2 stages; 1 GPU per stage; DP=TP=EP=SP=1; ZeRO stage 0;
  identity boundaries; schedule 1f1b; equal-sized microbatches (4).
- Model fixture: `Qwen/Qwen3-0.6B` (28 decoder layers, tied embeddings —
  the tie is intra-stage-safe only because embed and lm_head land on
  different stages and their gradient link is exercised by parity tests).
- Optimizer: AdamW defined in the DeepSpeed config (lr 3e-5) — never a
  preconstructed object (v1 contract).
- Provisional numerical tolerances vs the unsplit baseline (to be refined and
  frozen at P6): loss atol 1e-2 (BF16), parameter-gradient rtol 2e-2 /
  atol 1e-3, optimizer-update parity checked on selected parameters.

## Prior de-risking spikes (pre-P0, kept at workspace root)

`stitch.py`, `stage.py`, `pipeline.py`, `ray_pipeline.py`,
`microbatch_pipeline.py` — single-process and Ray-actor pipeline prototypes
verified grad-exact against the monolithic model. They inform P2 (external-
gradient backward), P3b (partitioning), P4 (1F1B ordering), P5 (stage worker),
and are not shipped in the package.
