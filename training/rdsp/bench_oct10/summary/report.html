rdsp vs Megatron on 9B: all results

4 of 5 layouts: rdsp is faster. In the other one it is about even.

Every run does the same work on both systems: same model, same rows, 64 rows per step, every row padded to 2,048 tokens. Step time is the median of steps 6–50.

Why, per run

  • Bridge · TP4 × PP2 × DP1: Bridge's vision encoder is 3.6 s per step slower. Profiled. Analysis →
  • Bridge · TP2 × PP2 × DP2: Not profiled.
  • Bridge · TP2 × DP4, no pipeline: Not profiled. No pipeline, so this compares the model code: Megatron + Transformer Engine vs Hugging Face + DeepSpeed.
  • MIMO · vision 1 GPU + TP2 × PP2: MIMO is held back by its vision GPU: slower vision encoder and a hand-off that blocks. Profiled. Analysis →
  • MIMO · vision 1 GPU + TP2 × DP2: Both are held back by their language GPUs, which run at about the same speed. Profiled. Analysis →

Limits

  • One run per system per layout. No repeats.
  • 3 of the 5 comparisons were profiled: Bridge TP4 × PP2 × DP1 and both MIMO layouts. The other two have step times only.
  • The MIMO layouts use 5 of the 8 GPUs; per-GPU numbers make them comparable to the 8-GPU runs.
  • Not run: 27B (fits only with full recompute on both systems) and the planned 4B layouts.
